### currently building

**Zizou — AI Coding Agent**
terminal-based coding agent with a custom context layer: a repo-map generator that extracts structural summaries (functions/classes/symbols + file:line) without ever loading full file contents into the prompt, paired with glob/grep/readFile tools for on-demand Level-0 exploration when the map isn't enough. system prompt assembly, tool execution, and approval flow all written from the ground up — no LangChain wrapper doing the thinking for me.

**Freelance: e-commerce builds**
I build storefronts for small businesses that don't want to bleed money on Shopify fees — fast, conversion-focused, MERN/Next.js front to back, real checkout flows, real deployment (Vercel/Render), not a template with a logo slapped on.

### other stuff I've shipped

- **AI-Based ML Online Compiler** — fully browser-based ML compiler, multi-agent LLM orchestrator streaming + executing Python client-side via Pyodide/WASM. zero server setup. >95% first-run execution success across ML tasks via a strict prompt contract + validation pipeline.
- **The Noting App** — AI doc summarizer + RAG chatbot for querying uploaded content, with Sarvam AI for podcast generation and Remotion for auto-generated video presentations.
- **Riverside Clone** — WebRTC remote-teaching platform, studio-quality recording, live ASR transcription feeding a contextual Q&A overlay grounded in the live transcript.
- **RAG Portfolio** — vector-less RAG pipeline letting visitors query my projects/skills/experience in natural language, pulling live context from Spotify, YouTube, and GitHub.
